### 3.6 网站统计（P0，v0.85）

**需求**：让我自己（也给访客）在页脚看到「累计多少人访问、今天多少人访问」；数据真实、口径可解释，且不接第三方、不侵犯隐私。

- **用户目标**：打开任意页面，页脚能看到实时更新的两个数字；我自己能确认数字可信（刷新不虚增、换设备会 +1）。
- **输入**：访客每次打开页面（浏览器 UA、访问路径、来源域名、IP —— IP 仅服务端内存瞬时使用）。
- **输出**：页脚一行 `累计 1,234 人次 · 今日 12 人次`（千分位；数字用等宽字体）。
- **成功标准**：见 §7「网站统计」三条。

**前端展示**
- 位置：全站页脚 `.ps-footer__inner` 内、备案行（`.ps-footer__beian`）**下方**新增一行 `.ps-footer__stats`；小字 13px、颜色同页脚元信息（低对比），整行居中；手机端单行不换行（数字过长时允许折行）。
- 文案：`累计 1,234 人次 · 今日 12 人次`；间隔符用中点 `·`，与页脚现有风格一致。
- **由 `site.js` 动态插入**（仅当页面存在 `.ps-footer__inner`）：不改 33 个页面的 HTML、不改 `tools/sync_articles.py` 的页脚模板，新增页面自动生效。
- 降级：接口失败 / 超时 1.5s / 返回格式不对 → **整行不插入**（不显示 0、`—` 或错误提示）；`file://` 双击打开时不发请求。
- 不阻塞渲染：在 `window.load` 之后发起；不改变页脚原有高度布局（插入时只追加一行）。

**统计口径（可判定）**
- **今日** = 当天（`Asia/Shanghai`）去重后的匿名访客数，即当日 UV。
- **累计** = 逐日 UV 相加（**人次**，非全站去重人数）；页脚文案写「人次」。
- **匿名标识** = `HMAC-SHA256(服务端密钥, 日期 + IP + UA)` 取前 16 位十六进制，只存哈希，不可逆、跨天不同。
- 同一天同一浏览器多次刷新 / 多页浏览：**UV 不变**，PV 每次 +1；换浏览器 / 无痕 / 次日再访问：UV +1。
- Bot / 预渲染（UA 含 bot / crawler / spider / headless、`Sec-Purpose: prefetch`）不计。
- PV 一并记录（供以后看人均浏览），**本期不展示**。

**明细字段（只落库，本期不做后台页）**
日期、匿名标识、页面路径、来源域名（Referer 主机名，无则空）、设备类型（手机 / 电脑 / 平板）；粗粒度地区（国家 / 省份）为 P1 预留，本期不采集。**不存明文 IP、不存完整 UA、不存 Cookie / localStorage / 浏览器指纹。**

**边界与假设**
- 假设①：数字对访客公开可见（公开计数是常见做法）；若之后想只对自己可见，再改成登录后显示。
- 假设②：先按「人次」而非「独立人数」对外表述，避免把多天重复访客算成新人的歧义。
- 边界：只统计 `chesterlee.cn` / `www.chesterlee.cn` 本站页面；`web/xunguang/` 副本页（无 `site.js`）不计入首版。
- 不做：第三方统计（百度 / 不蒜子 / Umami 等）、外链脚本、Cookie、后台图表页面、评论 / 点赞类互动统计。

### 5.1 网站统计（v0.85，自建）

- **前端（改 2 个文件，不动页面 HTML）**
  - `web/assets/js/site.js` 末尾新增统计模块（零依赖）：`window.load` 后 `fetch('/stats/hit', {method:'POST', keepalive:true, headers:{'Content-Type':'application/json'}, body: JSON.stringify({p: location.pathname, r: document.referrer ? hostOf(document.referrer) : ''})})`；1.5s 超时；成功且 `{total,today}` 均为有限数字，才把 `.ps-footer__stats` 插到 `.ps-footer__beian` 之后；任何异常直接返回。
  - `web/assets/css/site.css` 末尾追加 `.ps-footer__stats`（13px、`--font-mono` 数字、低对比、居中、`margin-top` 与备案行留 8px）。
- **服务端（新增目录，不参与静态站 rsync）**
  - 新目录 `server/stats/`：`index.js`（Node 22 原生 `http` + `crypto`，**零 npm 依赖**）+ `personal-stats.service`（systemd 单元）；启动与部署命令见 `usage/Running.md`。
  - 接口：`POST /stats/hit`（记录一次访问并返回汇总）、`GET /stats/summary`、`GET /stats/healthz`。
  - 监听 `127.0.0.1:8950`；Caddy 在 `chesterlee.cn, www.chesterlee.cn` 站点块内把 `/stats/*` 反代到该端口，其余路径仍直读 `/srv/chesterlee/site`；改完 `sudo caddy validate` → `sudo systemctl reload caddy`。
  - CORS 白名单：`https://chesterlee.cn`、`https://www.chesterlee.cn`、`http://localhost:5181`、`http://127.0.0.1:5181`；请求体 ≤1KB；字段白名单 + 长度截断（路径 ≤200、来源域名 ≤100）。
  - 限流：单 IP 60 次/分钟、600 次/小时，超限返回 429（前端静默）。
  - Bot / 预渲染过滤：UA 命中 `bot|crawler|spider|headless|preview`，或 `Sec-Purpose: prefetch`，直接返回汇总但不计数。
  - 存储：`/var/lib/personal-stats/store.json` —— `{salt, total, days: {"YYYY-MM-DD": {uv, pv, visitors:[hash], refs:{}, devices:{}, paths:{}}}}`；`visitors` 日哈希集合用于 UV 去重；写盘用「临时文件 + `rename`」原子替换；保留 400 天明细，累计总数不清零。
  - systemd：`personal-stats.service`（`User=ubuntu`、开机自启、崩溃重启）；匿名哈希密钥首次启动自动生成并存进 `store.json`，不出服务器。
  - 地区解析（**P1，本期未做**）：首版不引任何 IP 库、不解析地区；需要时再接离线库（`geoip-lite` / `ip2region`），内存解析后只存「国家 / 省份」。
- **上线与验证**
  - `rsync -az -e "ssh -i ~/.ssh/chesterlee_web" server/stats/ ubuntu@43.136.92.125:/srv/chesterlee/stats/` → 服务器 `sudo systemctl restart personal-stats`；
  - 本机 `curl -s https://chesterlee.cn/stats/healthz?cb=$(date +%s)`；真实浏览器打开首页看页脚；
  - 刷新 3 次：今日不变、接口 `pv` +3；换浏览器 / 无痕：今日 +1；
  - 断网模拟：页脚统计行不出现，页面其余正常；390 / 1280 两档无横向滚动。

## 7 成功标准

- 手机与电脑打开都不出现横向滚动，图片清晰且加载不卡。
- 访客 10 秒内看懂「这是谁、在做什么、有什么作品、写了什么」。
- 文章列表可读、每篇正文能正常打开，长文阅读不累眼。
- 全站无第三方依赖、无第三方统计脚本；统计仅限自建匿名聚合（无 Cookie、不存明文 IP）。
- **网站统计（v0.85）**：
  1. 任意页面页脚都能看到「累计 N 人次 · 今日 N 人次」，数字与服务器 `store.json` 一致；
  2. 同一浏览器当天刷新 / 多页浏览，累计与今日**都不增加**；换浏览器或无痕打开，今日 **+1**；
  3. 统计接口挂掉或断网时，该行**完全不出现**，页面其余内容、布局、宽度不受影响。

## 8 风险与应对

| 风险 | 应对 |
|---|---|
| 生活照体积大、加载慢 | 入库前压缩 + `loading="lazy"` |
| 图片缺失导致破图 | 用占位色块，不用假图 |
| 文章写多后页面难维护 | `tools/sync_articles.py` 一键从 Obsidian 同步（固定命名 `a-<hash8>` + 统一模板），列表页与首页数据自动重生成 |
| 隐私泄露 | 不写住址/电话，公开信息须用户确认 |
| 文字写多、违背"简洁" | 首页首屏等仍限 1–3 句；「关于我」页 v0.41 起按用户要求放完整版全文（已确认为例外） |
| 统计被刷量 / 数字虚高 | 按「日期 + IP + UA」哈希去重（同人当天只算 1 次）+ 单 IP 限流 + Bot / 预渲染过滤；页脚文案用「人次」，不承诺「独立人数」 |
| 统计服务挂掉影响页面 | 前端 1.5s 超时、失败即不插入该行；接口与静态站分离，统计挂了页面照常打开；`systemd` 崩溃自动重启 + `healthz` 巡检 |
| 数据丢失 / 磁盘损坏 | 每次写盘原子替换（临时文件 + `rename`）；数据只在服务器 `store.json`，需要时手动 `cp` 备份 |
| 隐私与合规争议 | 不写 Cookie、不存明文 IP / 完整 UA / 指纹；只存匿名哈希与粗粒度聚合；隐私口径写进 RPD 与 Running；用户可要求一键清空 `/var/lib/personal-stats/` |
| 改 Caddy 配置导致全站不可用 | 先 `sudo caddy validate --config /etc/caddy/Caddyfile` 再 `reload`；只新增 `/stats/*` 一条 handle，不动静态站路径 |
| 暂时看不到来源地区 | 本期页脚只展示累计 / 今日；地区列为 P1，后续接离线 IP 库再补，不影响现有计数 |
